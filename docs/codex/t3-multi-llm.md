# T3 Code Multi-LLM Orchestration (Codex Coordinator + Any T3 LLM)

This mode lets a **Codex thread inside T3 Code** act as the project Coordinator — matching the original Claude + T3 Code experience — while routing worker tasks by complexity across **any LLM provider configured in T3 Code** (`codex`, `opencode`, `antigravity`, `claudeAgent`, etc.).

## How it works

```text
you ──► Codex Coordinator (in T3 Code)
           │
           ├── simple task  ──► t3_thread_launch (e.g. flash / mini / haiku, effort: low)   ──┐
           ├── standard task──► t3_thread_launch (e.g. luna / sonnet / argon, effort: medium)─┼──► [T3O_SIGNAL_V1] wakes Coordinator
           └── complex task ──► t3_thread_launch (e.g. sol / opus / carbon, effort: high)   ──┘
```

- **Claude workers** automatically wake up the Codex Coordinator via the existing `hooks/register.mjs` `Stop` hook (`t3_thread_send` → `coordinatorThreadId`).
- **Non-Claude workers** (Codex, Antigravity, OpenCode, Gemini, etc.) receive a standardized `[T3O_WORKER_V1]` wake-up block generated by `t3o-codex t3-brief`, instructing them to call `t3_thread_send` with `[T3O_SIGNAL_V1]` when finished, blocked, or awaiting approval.
- **Zero breakage:** Existing `~/.t3-orchestration/config.json` and `hooks/register.mjs` remain untouched; tier routing policies live separately in `~/.t3-orchestration/t3-routing.json` (`0600`).

## Quick start

1. Link the CLI once:
   ```bash
   (cd ~/t3-orchestration/codex && npm link)
   ```

2. Inspect all enabled LLM providers configured in T3 Code:
   ```bash
   t3o-codex t3-providers
   ```

3. Configure complexity-based routing for your project (example):
   ```bash
   t3o-codex t3-route --project my-app --set simple=antigravity:gemini-3.8-flash-low:low
   t3o-codex t3-route --project my-app --set standard=codex:gpt-6-luna:medium
   t3o-codex t3-route --project my-app --set complex=codex:gpt-6.1-sol:high
   ```

4. Preview a resolved `modelSelection` or generate a full `t3_thread_launch` payload:
   ```bash
   t3o-codex t3-route --project my-app --tier simple --json
   t3o-codex t3-brief --project my-app --coordinator "<coord-thread-id>" \
     --title "Inspect auth middleware" \
     --brief "Read src/auth and list edge cases." \
     --tier simple --json
   ```

5. Inside T3 Code, open a Codex thread in your project and follow [codex/skills/t3-setup/SKILL.md](../../codex/skills/t3-setup/SKILL.md) to create and pin your `Orchestration` coordinator thread. Once set up, the coordinator follows [codex/skills/t3-orchestrate/SKILL.md](../../codex/skills/t3-orchestrate/SKILL.md).
